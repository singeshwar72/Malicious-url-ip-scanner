About CyberScan

Malicious URL & IP Scanner – Cyber Threat Detection and Risk Analysis System

Project Overview

CyberScan is a defensive cybersecurity web application developed as a B.Tech Computer Science & Engineering project. It provides automated threat detection and risk analysis for URLs and IP addresses using a transparent, rule-based scoring engine.

The application is designed for authorised, defensive use only. It does not perform port scanning, exploitation, brute-force, or any offensive cybersecurity operations. All analysis is read-only and passive unless an external reputation API is explicitly configured.

How It Works
  1. User submits a URL or IP address (IPv4 / IPv6).
  2. The input is validated and classified by the validators.py module.
  3. The appropriate scanner (url_scanner.py or ip_scanner.py) performs passive analysis.
  4. Detected indicators are passed to risk_engine.py, which calculates a deterministic 0–100 risk score using weighted rules.
  5. If external APIs are configured (VirusTotal, AbuseIPDB, IPinfo), their results are factored in.
  6. The result is stored in a local SQLite database and displayed as a detailed security report.
